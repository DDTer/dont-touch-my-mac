# Don’t Touch My Mac!

一个原生 macOS 菜单栏小工具：观察手部靠近趋势，弹出全屏警告，收手后恢复。支持英语、日语、简体中文。

## 使用

- 默认语言为“跟随系统”，按系统首选语言选择中/英/日，其他语言回退英语。
- 右上角可手动切换语言，立即更新控制面板、菜单栏、警告和应用错误文案；选择会保存。切回“跟随系统”会恢复自动解析。
- 配音随当前应用语言切换，三种语言各有 A/B/C 声线。日语 A 保留用户已选版本。声线、静音和灵敏度会保存。
- 点“预览警告”体验全屏；点“开启护屏”并允许摄像头后进入检测；Esc 可暂停。
- 关掉窗口后仍可从菜单栏操作；锁屏/睡眠会暂停。支持自定义本地图片。
- macOS 原生文件选择器、权限弹窗的系统按钮遵循系统语言；其应用说明已提供三语资源。

## 本地开发

完整 Xcode 工程：`DontTouchMyMac.xcodeproj`，Scheme 为 `DontTouchMyMac`。最低 macOS 14，使用 Xcode 运行或执行：

```sh
./Scripts/build.sh
```

构建输出：`build/Build/Products/Release/Don't Touch My Mac.app`。工程不依赖第三方运行库。若安装 XcodeGen，构建会从 `project.yml` 重新生成工程；未安装时直接使用已提交的 `.xcodeproj`。

构建脚本会运行已有检测回归，以及语言解析、手动覆盖、三语词条完整性和格式占位符检查。界面验收以实际原生截图为准。

## 工程结构

- `Sources/main.swift`：应用状态、控制面板、全屏警告、菜单栏。
- `Sources/Support/Localization.swift`：语言选择、系统语言解析、文案格式化。
- `Sources/Detection/`：相机与检测状态机。
- `Resources/*.lproj/`：三语应用文案和摄像头权限说明。
- `Assets/Voices/`：各语言的离线可爱风配音；不在运行时请求外部服务。
- `docs/detection-validation.json`：此前验证边界，未包含原始手部关键点或视频。

## 隐私与验证边界

相机画面仅在本机处理，不录制或上传；默认不启用相机。开发诊断和关键点回放为显式测试入口，其启动标记和原始数据不提交。

检测使用单目相机的尺度/骨段趋势，并非真正测距或系统触屏拦截。遮挡、过快接近、自然转手和估计噪声仍可能漏报或误报。此前 v0.5 对同一真实关键点片段从 0 次改善为 2 次触发并自动恢复，原生窗口回放也通过；这不代表独立真人三次动作已全通过，也不证明长期误报率合格。

当前为本地 ad hoc 签名，无开发者公证；生产分发、新触屏硬件、较旧系统、Intel 设备和长期耗电未验证。

## 配音来源

日语 A 由用户试听选定，三语均使用 Fish Audio Voice Design 按原创可爱动漫风描述生成，未模仿特定演员或角色。构建和运行只使用内置音频，不需要任何服务密钥。

如确需重新生成配音，先在当前终端从既有安全来源设置环境变量 `FISH_AUDIO_API_KEY`，然后运行 `python3 Scripts/generate_voices.py --languages en,zh`。该脚本默认跳过已有文件，显式加 `--force` 才替换；需要 Python 3 和 ffmpeg。未设置变量时脚本会提示退出，不影响 App 构建与离线运行。日语 A 已选定，默认不重生成。

## v0.9 检测优化

靠近判定改用持续可见的同一组掌部关节定位，结合掌骨与指骨的共同放大、轨迹趋势和横向移动占比。抬手向上不再直接按横向挥手处理；低位、近水平的键盘动作需要更强的放大证据。可靠骨段证据可使用更短窗口和最多 120 毫秒的有限预测，边界框输入仍保持较严格条件。相机检测频率提高，本机短测实际约 15 帧/秒；这不是所有设备的帧率保证。

警告期间会更新确认过的最近峰值姿态，避免“触发后继续靠近，再稍微收手却不恢复”。明确缩小需要持续 100 毫秒确认；无可靠手部证据约 420 毫秒后恢复，最短显示 280 毫秒，并保留短暂遮挡防抖。实际时间还包含取样与处理延迟。

Release 构建、33 个检测场景和原有本地化回归通过。同一组 **20 fps 模拟轨迹** 的触发从 0.65 秒提前到 0.50 秒；触发后继续靠近、再收回的样本约 0.10 秒恢复，而旧版没有恢复；手彻底消失的样本从 0.60 秒缩短至 0.40 秒恢复。打字样式的手指屈伸、小幅尺度噪声、带轻微缩放的横向挥手和关节遮挡等模拟负例未触发。以上时间不是独立真人的端到端响应承诺。

此前 2175 帧无动作标签的真实关键点已离线对照：旧版 10 次警告，新版 15 次。多出的警告可能来自更快恢复后重新触发、此前漏掉的动作或误报；不能据此宣称准确率提升。既有警告的最近触发时间有提前、相同及一例约 0.30 秒延后，不能宣称所有动作都提前。详细结果与本机短测边界见 `docs/detection-v09-validation.json`。

需要复现时，用 `./Scripts/replay_detection.sh /绝对路径/本地关键点.jsonl /绝对路径/汇总.json`。工具只输出事件时间与计数；原始相机/关键点数据保持本地且不入库。长时间真人打字/挥手的误报率、更多角度和光照、Intel/较旧系统仍需验证。

本机约 103 秒短测记录到 3 次触发、3 次恢复，帧间隔中位数约 66.7 毫秒，视觉处理耗时中位数 7.92 毫秒、P95 为 26.64 毫秒。用户完成正常打字 10 秒、横向挥手 3 次、自然靠近并收手 3 次后，反馈“触发和恢复正常，没有误报”，与日志中的 3 次触发/3 次恢复吻合。这是本轮短测验收，不代表长期或所有光照角度的误报率。诊断开关已关闭，原始关键点仅保存在本地工作目录。
